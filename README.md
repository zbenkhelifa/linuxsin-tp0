## Comment faire ce TP

1. **Fork ce repo** — bouton "Fork" en haut à droite
2. **Ouvre `tp0.sh`** dans l'onglet "Code"
3. **Complète les fonctions** — remplace les `# ÉCRIS TA COMMANDE ICI`
4. **Commit** — bouton "Commit changes" en bas
5. **Onglet "Actions"** — lis ta correction (✅ / ❌)

Ton fichier `RESULTATS.md` est mis à jour automatiquement après chaque commit.

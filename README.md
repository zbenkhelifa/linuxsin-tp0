# TP0 — Mise en route

> LinuxSIN · STI2D SIN · Terminale

## Comment faire ce TP

1. **Fork ce repo** — bouton "Fork" en haut à droite
2. **Ouvre `tp0.sh`** dans l'onglet "Code"
3. **Complète les fonctions** — remplace les `# ÉCRIS TA COMMANDE ICI`
4. **Commit** — bouton "Commit changes" en bas
5. **Onglet "Actions"** — lis ta correction (✅ / ❌)

Ton fichier `RESULTATS.md` est mis à jour automatiquement après chaque commit.

---

## Recevoir tes résultats sur ton téléphone

Après chaque commit, tu peux recevoir une notification avec ton score directement sur ton téléphone.

1. Installe l'app **ntfy** — [Android](https://play.google.com/store/apps/details?id=io.heckel.ntfy) · [iPhone](https://apps.apple.com/app/ntfy/id1625396347)
2. Dans l'app, abonne-toi à ce canal (remplace `TON-PSEUDO` par ton pseudo GitHub) :

```
https://ntfy.sh/linuxsin-TON-PSEUDO
```

> Exemple : si ton pseudo GitHub est `alice-dupont`, abonne-toi à `https://ntfy.sh/linuxsin-alice-dupont`

Tu recevras une notification à chaque correction avec ton score.
